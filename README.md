# Machine Learning From Scratch

Implementing machine learning algorithms from scratch using Python and NumPy to understand the mathematics, concepts, and internal mechanics behind them.

## 🎯 Goal

The goal of this repository is to build machine learning algorithms from scratch and understand how they work internally, rather than simply using ready-made implementations.

## 📚 Algorithms

### Supervised Learning

* [x] Linear Regression
* [ ] Logistic Regression
* [ ] K-Nearest Neighbors (KNN)
* [ ] Naive Bayes
* [ ] Decision Tree
* [ ] Random Forest
* [ ] Support Vector Machine (SVM)

### Unsupervised Learning

* [ ] K-Means Clustering
* [ ] Principal Component Analysis (PCA)

### Neural Networks

* [ ] Perceptron
* [ ] Neural Network
* [ ] Backpropagation
